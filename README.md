pot mensuel, ordre immuable, score de fiabilité.

- **DESIGN.md** — la loi visuelle : tokens Tailwind v4, sémantique, interdits
- **maquette/solid_maquette.html** — maquette interactive des 14 écrans du MVP
- **references/NOTES.md** — références design externes (structure uniquement)
- **.claude/skills/** — design-sol (UI) et moncash-flow (paiements)
